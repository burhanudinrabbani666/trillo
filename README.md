**Trillo** is a fictional travel and hospitality platform designed to provide a seamless experience for users who want to plan vacations, book hotels, and reserve flights in one place.

The platform focuses on clean UI layout, responsive design, and modern CSS architecture, delivering an intuitive and visually engaging user experience.

## About this project

This project was developed as part of my continuous learning journey in advanced modern CSS development.
It is based on coursework from Jonas Schmedtmann’s Advanced CSS and Sass course and is recreated strictly for educational and skill development purposes.

The primary goal of this project is to strengthen my expertise in:

- Advanced layout engineering
- Scalable CSS architecture
- Efficient Flexbox implementation
- Professional SCSS structuring
